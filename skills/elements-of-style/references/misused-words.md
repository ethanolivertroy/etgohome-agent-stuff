# Words and expressions commonly misused

Condensed from Chapter V of *The Elements of Style* (Strunk, 1920). Strunk's advice: if one of
these slips in, recast the sentence to say what you actually mean rather than swapping one word.

Entries marked **(dated)** reflect 1920 usage; mention them only if the user asks for strict
Strunk, otherwise leave the text alone.

| Expression | Guidance | Instead of → write |
| --- | --- | --- |
| all right | Two words. | alright → all right |
| as good or better than | Rearrange so each comparison is complete. | as good or better than his → as good as his, or better |
| as to whether | *Whether* is enough. | |
| but (after doubt, help) | Unnecessary. Don't stack *but* on *but*. | I have no doubt but that → I have no doubt that |
| can / may | *Can* = able; *may* = permitted. | |
| case | Usually padding. | In many cases, the rooms were poorly ventilated → Many of the rooms were poorly ventilated |
| certainly, very, so (intensifier) | Use sparingly; choose a word strong in itself. | so delightful → delightful |
| character, nature (of a … character) | Redundant. | acts of a hostile character → hostile acts |
| clever | Reserve for ingenuity in small matters. | |
| compare to / compare with | *To* = liken different things; *with* = contrast similar things. | |
| consider (as) | No *as* when it means "believe to be". | I consider him as competent → I consider him competent |
| different than | Use *different from*. | |
| divided into / composed of | Plays are divided into acts; poems are composed of stanzas. | |
| due to | Not an adverb meaning *because of*. | He lost, due to carelessness → He lost because of carelessness |
| effect / affect | *Effect* (n.) result, (v.) bring about; *affect* = influence. Avoid vague "effects" in describing art. | |
| etc. | Only when the rest is obvious; never after *such as* or *for example*. | |
| fact | Only for verifiable matters, not judgments. | |
| factor, feature | Hackneyed; say what actually happened. | His training was the great factor in his winning → He won by being better trained |
| he is a man who | Redundant. | He is a man who is very ambitious → He is very ambitious |
| interesting | Don't announce it; make it so. | An interesting story is told of… → (tell the story) |
| kind of, sort of | Not a substitute for *rather*. | kind of tired → rather tired |
| less / fewer | *Less* for quantity, *fewer* for number. | less men → fewer men |
| like / as | *Like* before nouns, *as* before clauses. | He thought like I did → He thought as I did |
| along these lines | Overworked. | spoke along the same lines → spoke to the same effect |
| literally | Not for exaggeration. | literally dead with fatigue → dead tired |
| lose out, win out, try out | The particle adds nothing. | |
| most (for almost) | | most everybody → almost everybody |
| one of the most | Threadbare opener; also takes a plural verb in the relative clause. | one of the ablest men that has → that have |
| participle for gerund | Prefer the possessive with a verbal noun. | Do you mind me asking → Do you mind my asking |
| people / public | *People* is political; *public* is audience or customers. | |
| phase | A stage of change, not an aspect or topic. | another phase of the subject → another point |
| respective, respectively | Usually omit. | |
| student body | | a member of the student body → a student |
| system | Often unneeded. | the dormitory system → dormitories |
| thanking you in advance | Write "Will you please…" and thank them afterward. | |
| viewpoint | Not a substitute for *view* or *opinion*. | |
| while | Means "during the time that"; don't use for *and*/*but*, and use for *although* only when unambiguous. | …ground floor, while the rest is manufacturing → …ground floor; the rest is manufacturing |
| whom (before "he said") | It's the subject of the next verb. | whom he said would send → who he said would send |
| worth while | Applies to actions; never before a noun. | His books are not worth while → His books are not worth reading |
| would (habitual) | Plain past is shorter and stronger. | Once a year he would visit → Once a year he visited |
| claim, state, possess | Not substitutes for *say*, *declare*, *have*. **(dated** as strict rules; still good advice against inflated verbs) | He possessed great courage → He had great courage |
| data (always plural) | **(dated)** Either is accepted now; follow house style. | |
| dependable, near by, fix, have got | **(dated)** Standard today. | |
| however (first in sentence) | **(dated)** Fine today in moderation. | |
| shall / will, should / would by person | **(dated)** Use modern *will/would*. | |
| split infinitive | **(dated)** Split when it reads better. | |
| they (for everyone/someone) | **(dated)** Singular *they* is standard; keep it. | |
| to-day, to-night, to-morrow | **(dated)** today, tonight, tomorrow. | |
